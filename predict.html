01프로젝트 한눈에 보기

핵심 구현

5개 데이터셋의 상이한 라벨 기준을 페르소나별 판단 근거와 토론, 판정 에이전트로 연결함

Motivation

혐오 표현 탐지 모델은 학습된 데이터셋에서는 잘 작동하지만 다른 데이터셋에서는 성능이 떨어집니다. 데이터셋마다 라벨링 기준이 다르기 때문이며, 기존 통합·증강 방식으로는 이 근본 차이를 극복하기 어렵음.

Research goal

데이터셋마다 상이한 라벨링 기준으로 발생하는 혐오 표현 탐지 모델의 일반화 성능 저하 한계를 극복함.

02해결 방법

데이터셋마다 서로 다른 혐오표현 판단 기준을 각각의 독립 에이전트 관점으로 구성하고, 유사 사례 검색과 토론을 통해 최종 라벨을 결정하는 두 단계 구조를 설계함.

101 / PRE

데이터셋별 판단 근거 구성

5개 데이터셋의 라벨 기준을 에이전트별 관점으로 정의하고, FAISS로 유사 사례를 검색해 혐오 및 비혐오 판단의 참조 근거를 생성함.

202 / DEBATE

상반된 판단 비교

혐오 및 비혐오 에이전트가 근거를 제시하고 상대 주장을 검토하도록 토론을 구성함. 판단 기준의 충돌을 명시적으로 드러냄.

303 / DICT

Judge의 최종 판정

판정 에이전트가 토론 내용과 검색 근거를 종합해 최종 라벨과 이유를 생성하도록 설계함.

404 / VALIDATION

라운드 제한과 일반화 검증

토론 반복 시 환각과 지연이 늘어나는 현상을 점검하고 2라운드로 제한함. 5개 벤치마크에서 정확도를 검증함.

핵심 설계 판단

서로 다른 데이터셋의 기준을 하나로 합치지 않고 독립된 판단 근거로 보존함. 검색된 사례와 두 관점의 반박을 Judge가 종합하도록 하여 교차 데이터셋 분류 문제를 해결함.

03구현 및 연구 방법

  1. 데이터셋 간 라벨링 기준의 차이를 독립적 관점으로 정의하고, LLM 기반 멀티 에이전트 토론으로 합의를 도출하는 프레임워크 설계
  2. Phase 1 (PRE) — 5개 데이터셋 기준과 OpenAI 임베딩·FAISS 기반 유사 사례 검색을 결합해 각 에이전트의 독립적 관점을 구성, 혐오 여부·근거를 생성해 양측 진영(Hate/Non-hate)의 Reference로 저장
  3. Phase 2 (DICT) — 두 디베이터 에이전트가 2라운드 토론(주장 → 반박·입장 수정)을 진행하고, 판사(Judge) 에이전트가 전체를 종합해 최종 라벨과 균형 잡힌 근거를 도출

Engineering challenges & solutions

문제 1에이전트가 각자 부여받은 관점만 일방적으로 주장해 합의 도출·라벨링 정확도 저하

해결무조건적 다수결을 배제하고, 상대방 근거로 반박하는 구조와 판사 에이전트가 양측 의견을 종합해 최종 판결·균형 잡힌 근거를 내는 중재 페이즈(DICT) 도입

국제학술대회 성과
