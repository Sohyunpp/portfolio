01프로젝트 한눈에 보기

핵심 구현

15만 건 커뮤니티 게시글을 질의 확장과 벡터 검색, 대표 의견 요약으로 처리하여 LLM에 전달함

커뮤니티 게시글 15만 건에서 질문 관련 근거와 대표 의견을 추출해 에이전트 응답을 생성하고 여론 일치도와 가치관 정렬을 검증함.

입력

커뮤니티 게시글

주제별 관련 게시글을 검색해 평가 대상 데이터셋 구성.

처리

의견 추출 및 Agent 구성

핵심 논점을 추출해 LLM Agent가 활용하도록 구성.

02해결 방법

대규모 커뮤니티 게시글을 LLM에 모두 주입하면 무관한 정보와 상충하는 주장이 섞이는 문제를 해결하기 위해, 주제 관련 문서를 검색한 뒤 대표 의견만 추려 에이전트 입력으로 구성함.

101 / RETRIEVAL

주제별 검색 후보 추출

질문의 찬반 논거를 확장하고 e5-multilingual-small 임베딩 및 FAISS로 커뮤니티별 유사 게시글 상위 50건을 검색함.

202 / SUMMARIZATION

대표 의견 추출

검색 결과에서 2~4개 후보 의견을 생성하고 게시글을 유사 의견에 할당함. 가장 많은 게시글이 속한 군집의 의견을 대표 의견으로 선정함.

303 / AGENT

응답 컨텍스트 구성

선정한 대표 의견을 LLM 에이전트에 제공해 커뮤니티의 주요 관점이 반영된 답변을 생성함.

404 / EVALUATION

두 평가 축으로 검증

87개 여론 문항의 응답 정확도와 23개 가치관 문항의 실제 집단 응답 분포 차이를 측정함.

핵심 설계 판단

질의 확장과 Top-50 검색으로 관련성을 확보하고 대표 군집만 컨텍스트에 남겨 정보 혼입을 줄임. 여론 일치도와 가치관 정렬을 별도로 평가함.

03구현 및 연구 방법

101 DATA

3개 커뮤니티

총 785,208건 원천 게시글에서 커뮤니티별 5만 건씩 선별해 분석 데이터 15만 건 구성.

202 RETRIEVAL

Query Expansion + FAISS

찬반 관점을 포함한 질의를 확장하고 e5-multilingual-small 임베딩으로 커뮤니티별 Top-50 검색.

303 SUMMARY

대표 의견 군집화

2~4개 의견 후보에 문서를 매핑해 가장 대표성 높은 주장의 요약문 생성.

404 EVALUATION

두 평가 차원

87개 여론 문항과 23개 가치관 문항을 활용해 응답 일치도와 KL Divergence 분석.

04핵심 결과

05개인 기여 및 논문

한국HCI학회 논문지 21권 1호에 공동저자로 참여했으며, 커뮤니티 데이터에서 관련 근거를 선별하고 LLM Agent 입력과 평가로 연결하는 연구를 수행함.

주요 연구 수행 내용

검색 근거 선별, 대표 의견 압축, Agent 평가

  • 데이터 및 검색

    3개 커뮤니티에서 선별한 15만 건 게시글을 대상으로 Query Expansion과 FAISS Top-50 검색을 연결해 질문 관련 근거를 추출함.

  • 컨텍스트 구성

    검색 문서를 대표 의견 2~4개 후보로 군집화한 뒤 주요 의견을 요약해 Agent 입력으로 구성하고, 생성과 반복 평가에 사용하는 모델의 역할을 구분함.

  • 성능 검증

    45개 모델 및 구성 조합을 비교하는 실험에 참여하고, 87개 여론 문항과 가치관 정렬 평가로 응답 품질을 검증함.
