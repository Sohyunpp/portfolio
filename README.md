# Sohyun Park | Research Portfolio

Static HTML research portfolio for GitHub Pages.

## Deployment

1. Create a **public** GitHub repository named `portfolio`.
2. Upload the **contents** of this folder to the repository root so that `index.html` is at the root.
3. Open **Settings > Pages** and set **Build and deployment > Source: Deploy from a branch**, then choose **main** and **/(root)** and save.
4. Site URL: `https://sohyunpp.github.io/portfolio/` (once Pages is enabled and deployment completes).

Includes all HTML files, linked images, fonts, video, PDFs and JavaScript. `.nojekyll` is included for static publishing.
