01프로젝트 한눈에 보기

핵심 구현

정치 뉴스의 언어적 특성을 추출해 이미지 생성 프롬프트로 연결하고 102명 사용자 평가를 수행함

뉴스 기사 특성으로 SDXL 이미지 생성 프롬프트를 구성하고, 원본 이미지와 생성 이미지 2종을 102명 사용자 평가로 검증함.

문제

AI 생성 뉴스 이미지의 수용성 검증 필요

뉴스의 이미지 생성 방식이 독자 인식에 주는 영향을 실험으로 확인할 필요가 있었음.

접근

조건별 이미지 비교 및 사용자 평가

원본 이미지와 생성형 AI 이미지를 비교하고, 신뢰도와 이해도 등 평가 기준을 측정함.

02해결 방법

뉴스 기사의 내용과 논조를 이미지 생성 입력으로 구조화하고, 원본 이미지와 두 종류의 AI 생성 이미지를 비교해 실제 독자의 이해와 선호를 검증함.

101 / FEATURE EXTRACTION

뉴스 특성 추출

기사 감정, TF-IDF 키워드, 제목 및 진보·보수 매체의 언어적 특징을 분석해 프롬프트 구성 요소로 정리함.

202 / IMAGE GENERATION

SDXL 기반 생성

기사 전체 내용만 활용한 Simple 이미지와 추출한 특징을 결합한 제안 방법 이미지를 생성함.

303 / COMPARISON

세 이미지 유형 비교

원본 뉴스 이미지, Simple 생성 이미지, 제안 방법 이미지를 동일 기사 조건에서 비교함.

404 / HUMAN STUDY

102명 사용자 평가

뉴스 내용 반영성과 이해도를 평가하고, 보도 유형과 독자의 정치 성향별 선호 차이를 통계적으로 검증함.

핵심 설계 판단

생성 이미지의 적절성은 모델 출력만으로 판단하지 않고 실제 독자 평가로 검증함. 편향 보도와 사실 보도 모두에서 정치 성향에 따른 이미지 선호 차이가 유의하게 나타남.

03구현 및 연구 방법

101

기사 데이터 수집

진보·보수 언론 기사에서 제목과 본문, 이미지를 수집하고 전처리함.

202

생성 프롬프트 구성

감정 분석, 키워드, 언어 특성, 제목을 SDXL 생성 프롬프트로 통합함.

303

세 이미지 유형 비교

원본 이미지, 단순 생성 이미지, 제안 방법 이미지의 기사 반영성과 이해도를 평가함.

404

102명 사용자 평가

진보 41명, 보수 41명, 중도 20명 대상 연구 수행. 정치 성향별 선호 차이 검증.

04핵심 결과

생성형 AI 이미지는 뉴스 내용 이해에 활용될 가능성을 보여줌. 동시에 이미지 유형과 생성 여부에 따른 신뢰성 인식 차이가 관찰됨. 결과 해석 시 사용자의 정치적 관점을 함께 고려함.

정치 성향별 이미지 선호 차이

논문에서 보고한 카이제곱 통계량을 비교함.

7.66
